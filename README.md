# redmine_sound_level

A Redmine wiki macro that tabulates the **estimated sound pressure level (SPL) at several distances** from a source with a known level. Useful on project wikis and issues for noise checks, site surveys, equipment specs or safety notes: write the rated level once and get the level at 25, 50, 100, 250, 500 and 1000 ft (or m).

```
{{sound_level(150, 10, ft)}}
```

renders:

| Distance (ft) | Estimated SPL (dB) | Change vs 10 ft (dB) |
|---:|---:|---:|
| 25 | 142.0 | -8.0 |
| 50 | 136.0 | -14.0 |
| 100 | 130.0 | -20.0 |
| 250 | 122.0 | -28.0 |
| 500 | 116.0 | -34.0 |
| 1000 | 110.0 | -40.0 |

The table has a caption ("150 dB at 10 ft") and a one-line note that the values are estimates.

## Formula

Free-field point source, inverse-square law:

```
L(d) = L_ref - 20 * log10(d / d_ref)
```

About 6 dB less for every doubling of distance. This is the same formula as `spl_at_distance` (no air absorption) in the tested Python package [trainhorn-calc](https://github.com/train-horn/trainhorn-calc). The unit tests check the plugin against 22 values generated by that package.

## Requirements

- Redmine 5.0 or later (`requires_redmine version_or_higher: '5.0.0'`). Written for Redmine 5.x and 6.x.
- No gems, no database migrations, no settings.

## Install

```sh
cd /path/to/redmine/plugins
git clone https://github.com/train-horn/redmine_sound_level.git
# or download the v1.0.0 release and unpack it as plugins/redmine_sound_level
```

Restart Redmine (for example `touch tmp/restart.txt`, or restart the app server / container). The plugin then appears in *Administration → Plugins*, and the macro is listed in the wiki's macro list (`{{macro_list}}`).

To uninstall, delete `plugins/redmine_sound_level` and restart. Nothing is stored in the database.

## Usage

```
{{sound_level(SOURCE_DB)}}
{{sound_level(SOURCE_DB, REF_DISTANCE)}}
{{sound_level(SOURCE_DB, REF_DISTANCE, UNIT)}}
{{sound_level(SOURCE_DB, REF_DISTANCE, UNIT, distances=D1 D2 D3)}}
```

| Argument | Meaning | Default |
|---|---|---|
| `SOURCE_DB` | Level in dB at the reference distance, 0 to 250. Required. | none |
| `REF_DISTANCE` | Distance at which `SOURCE_DB` applies, greater than 0. | `10` |
| `UNIT` | `ft` or `m` (also `feet`, `meters`, `metres`). Applies to all distances. | `ft` |
| `distances=` | Up to 20 distances greater than 0, separated by spaces, `;`, `\|` or `/` (commas split macro arguments in Redmine). | `25 50 100 250 500 1000` |

Examples:

```
{{sound_level(150, 10, ft)}}                         horn rated 150 dB at 10 ft
{{sound_level(120, 1, m)}}                           120 dB at 1 m, distances in metres
{{sound_level(105, 3, m, distances=5 10 20 40)}}     custom distances
{{sound_level(150, 10, ft, distances=5)}}            closer than the reference: +6.0 dB
```

Invalid input does not break the page. Redmine shows its usual macro error box listing every problem at once, for example:

> Error executing the sound_level macro (source level must be a number, got "loud"; unit must be ft or m, got "yd")

Labels and messages are in `config/locales/en.yml` and can be translated.

## Limitations

- Free field only: no ground reflection, walls, barriers, wind or temperature gradients, and no air absorption. Real outdoor levels can be several dB higher or lower, and air absorption matters at long range and high frequencies.
- Not valid very close to a large source (inside roughly one or two source sizes).
- Results are estimates, not measurements, and are not a legal noise assessment.

For an interactive version of the same calculation, see the [Train Horn decibel distance calculator](https://train-horn.com/tools/decibel-distance/).

## Tests

The math, argument parsing, HTML output and plugin registration are tested with plain minitest; no Redmine install is needed:

```sh
rake test
# or
ruby test/unit/calculator_test.rb && ruby test/unit/macro_test.rb
```

`test/unit/macro_test.rb` loads `init.rb` against a small stand-in for the Redmine plugin and macro API and calls the macro block the way Redmine does. Tested with Ruby 2.6 (minitest 5.11) and Ruby 4.0 (minitest 6.0). The 1.0.0 release has not yet been rendered inside a running Redmine instance by the author; please open an issue if it misbehaves on your version.

`tools/gen_vectors.py` regenerates `test/fixtures/core_vectors.json` from the Python core.
